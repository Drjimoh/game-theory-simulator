## Game Theory Simulator

An interactive Jupyter Notebook that demonstrates fundamental and advanced concepts in Game Theory through simulation, visualization, and statistical analysis.

This project is designed for students, lecturers, researchers, business analysts, strategy professionals, and anyone interested in understanding how rational agents make decisions under competition and cooperation.

### Overview

Game Theory is the mathematical study of strategic decision-making. It helps explain behavior in economics, business, politics, banking, military strategy, artificial intelligence, and social systems.

This notebook brings Game Theory concepts to life through practical simulations using Python.

Rather than simply explaining the theory, the notebook allows users to:

Simulate strategic interactions
Compare competing strategies
Observe emergent behaviors
Analyze long-run outcomes
Visualize payoffs and equilibrium dynamics
Explore cooperation versus competition

## Installation

Clone the repository:

git clone https://github.com/drjimoh/game-theory-simulator.git

cd game-theory-simulator


Install dependencies:

pip install numpy pandas matplotlib seaborn jupyter


Launch Jupyter:

jupyter notebook


Open:
